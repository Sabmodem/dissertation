interface Trainer <<Core>> {
  + train(input: ProcessorInput) : void
}

class AutoencoderModel <<Model>> {
  - encoder: Sequential
  - decoder: Sequential
  - autoencoder: Model
  - latent_dim: int
  - input_dim: int
  ..
  + call(inputs: Tensor) : Tensor
  + get_reconstruction_error(inputs: Tensor) : float
}

note right of AutoencoderModel
  <b>Нейросетевая архитектура</b>
  
  Input (input_dim)
  → Dense(128, ReLU)
  → Dense(64, ReLU)
  → Dense(latent_dim=16, ReLU)
  → Dense(64, ReLU)
  → Dense(128, ReLU)
  → Dense(input_dim, Sigmoid)
  
  <b>latent_dim = 16</b> — умеренное сжатие
  <b>loss = MSE</b>, <b>optimizer = Adam</b>
  early stopping, обучение только на Non-Fraud
end note

class AETrainer <<User>> {
  - model: AutoencoderModel
  - threshold: float
  - scaler: StandardScaler
  - model_path: str
  - input_dim: int
  - latent_dim: int
  ..
  + train(input: FraudDetectionInput) : void
  - filter_non_fraud(input: FraudDetectionInput) : ndarray
  - compute_threshold(model: AutoencoderModel, X_val: ndarray) : float
  - save_artifacts() : void
}

note bottom of AETrainer
  <b>Реализация интерфейса Trainer</b>
  (обучение без учителя)
  
  1. Фильтрует ТОЛЬКО Non-Fraud (label=0)
  2. Разбивает на train/validation (80/20)
  3. Обучает AutoencoderModel
  4. Вычисляет порог: 95-й перцентиль MSE
     на валидации
  5. Сохраняет модель и порог
  
  <b>95-й перцентиль</b> — снижает ложные
  срабатывания (~5% нормальных могут
  иметь повышенную ошибку)
end note

AETrainer .up.|> Trainer : реализует
AETrainer *-- AutoencoderModel : композиция
FraudDetectionInput .. AETrainer : <<использует>>
