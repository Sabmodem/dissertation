note bottom of RFTrainer
  <b>Реализация интерфейса Trainer</b>
  
  <b>Вход:</b> List<FraudDetectionInput> с
  combined_features и labels.
  
  <b>Обучение:</b>
  1. Извлекает X (combined_features) и y (labels)
     из всего списка
  2. RandomizedSearchCV по сетке:
     n_estimators: {100, 200, 500}
     max_depth: {10, 20, None}
     min_samples_split: {2, 5, 10}
     class_weight: {balanced, None}
  3. StratifiedKFold (5 фолдов)
  4. Метрика: F1-score (баланс Precision/Recall)
  
  <b>Сохраняет:</b>
  • rf_model.joblib
  • feature_names.json
  
  <b>Важно:</b> получает список целиком,
  извлекает все признаки и метки
  для обучения одной модели.
end note
