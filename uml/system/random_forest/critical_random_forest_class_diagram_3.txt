note bottom of RFInterpreter
  <b>Реализация интерфейса Interpreter</b>
  
  <b>Получает:</b> List<FraudDetectionOutput>
  (все результаты инференса сразу)
  
  <b>Постобработка (XAI) для каждого результата:</b>
  1. Вычисляет SHAP-значения
     (TreeExplainer — быстро для деревьев)
  2. Извлекает топ-K влиятельных признаков
  3. Формирует объяснение:
     какие признаки и в какую сторону
     повлияли на решение
  
  <b>Агрегированная интерпретация:</b>
  • Сводная статистика по всем документам
  • Распределение fraud_probability
  • Общие top-K признаки по всему набору
  • Сравнительный анализ результатов
  
  <b>Принимает оба DTO:</b>
  • FraudDetectionOutput — результат
  • FraudDetectionInput — признаки для SHAP
  (входные данные доступны через
  атрибуты FraudDetectionOutput)
  
  <b>В Production:</b> объяснения сохраняются
  в БД для аудита (требование XAI из гл. 1-2).
end note
