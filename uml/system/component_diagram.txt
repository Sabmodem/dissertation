note top of User
  <b>Пользовательские реализации</b>
  Конкретные классы для задачи
  антифрода на текстах MD&A.
  
  <b>Один Preparator</b> обслуживает
  три разных метода — иллюстрация
  технологической нейтральности
  фреймворка.
  
  <b>Три Processor'а</b> — три парадигмы:
  правила, supervised, unsupervised.
  
  <b>Три Interpreter'а</b> — три способа
  объяснения результатов (XAI).
end note

note bottom of Ext
  <b>Внешние зависимости</b>
  полностью под контролем разработчика.
  
  Фреймворк не диктует:
  • формат файлов
  • тип базы данных
  • способ визуализации
  
  <b>Артефакты модели:</b>
  для каждого метода — свой набор
  файлов в соответствующих форматах.
end note
