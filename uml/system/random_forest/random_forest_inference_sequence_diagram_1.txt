@startuml
!theme plain
skinparam participantBackgroundColor LightYellow
skinparam participantBorderColor DarkSlateGray
skinparam sequenceArrowColor DarkSlateGray

actor "Исследователь" as Dev
participant "InferencePipeline" as Inf
participant "TextFraudPreparator" as Prep
participant "RFProcessor" as RFProc
collections "Файловая\nсистема" as FS

Dev -> Inf : run(rawData)
activate Inf

Inf -> Prep : prepare(rawData)
activate Prep

note right of Prep
  <b>fit_mode = False</b>
  Загружает TfidfVectorizer и Scaler
  с диска, применяет к новым данным.
  
  Возвращает List<FraudDetectionInput>
  с combined_features для всех документов.
end note

Prep -> FS : загружает артефакты\n(TfidfVectorizer, StandardScaler)

Prep --> Inf : List<FraudDetectionInput>\n(combined_features для всех документов)
deactivate Prep

Inf -> RFProc : process(List<FraudDetectionInput>)
activate RFProc

RFProc -> FS : загружает артефакты ОДИН раз\n(rf_model.joblib, tfidf_vectorizer.pkl,\nfeature_scaler.pkl, feature_names.json)

note right of RFProc
  <b>Инференс RF</b>
  Получает список всех входов.
  Модель загружается ОДИН раз.
  
  Для каждого элемента списка:
  1. Извлекает combined_features
  2. model.predict_proba() → вероятность fraud
  3. model.predict() → метка класса
  4. Формирует FraudDetectionOutput:
     prediction, fraud_probability,
     method_name = "RandomForest"
  
  Возвращает List<FraudDetectionOutput>
  со всеми результатами.
end note

RFProc --> Inf : List<FraudDetectionOutput>
deactivate RFProc

@enduml
