@startuml
!theme plain
skinparam participantBackgroundColor LightYellow
skinparam participantBorderColor DarkSlateGray
skinparam sequenceArrowColor DarkSlateGray

actor "Исследователь" as Dev
participant "InferencePipeline" as Inf
participant "TextFraudPreparator" as Prep
participant "AEProcessor" as AEProc
collections "Файловая\nсистема" as FS

Dev -> Inf : run(rawData)
activate Inf

Inf -> Prep : prepare(rawData)
activate Prep

note right of Prep
  <b>fit_mode = False</b>
  Загружает TfidfVectorizer и Scaler,
  применяет к новым данным.
  Возвращает List<FraudDetectionInput>
  с combined_features (без меток)
  для всех документов.
end note

Prep -> FS : загружает артефакты\n(TfidfVectorizer, StandardScaler)

Prep --> Inf : List<FraudDetectionInput>\n(все документы)
deactivate Prep

Inf -> AEProc : process(List<FraudDetectionInput>)
activate AEProc

AEProc -> FS : загружает артефакты ОДИН раз\n(autoencoder_model.keras,\nanomaly_threshold.json)

note right of AEProc
  <b>Инференс AE</b>
  Получает список всех входов.
  Модель и порог загружаются ОДИН раз.

  <b>Важно:</b> combined_features уже
  нормализованы Preparator'ом.
  AEProcessor НЕ загружает Scaler.

  Для каждого элемента списка:
  1. Извлекает combined_features
    (уже нормализованные)
  2. model.predict() → восстановленный вектор
  3. MSE = средний квадрат ошибки
  4. anomaly_score = MSE / threshold
  5. Если MSE > threshold → prediction = 1
  6. Формирует FraudDetectionOutput:
     prediction, anomaly_score,
     method_name = "Autoencoder",
     explanation = {mse, threshold}
  
  Возвращает List<FraudDetectionOutput>
  со всеми результатами.
end note

AEProc --> Inf : List<FraudDetectionOutput>
deactivate AEProc

@enduml
