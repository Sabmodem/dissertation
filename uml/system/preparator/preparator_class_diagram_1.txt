class LinguisticFeatureExtractor <<Utility>> {
  + extract(raw_text: str) : dict
  ..
  - compute_word_count(text: str) : int
  - compute_fog_index(text: str) : float
  - compute_flesch_reading_ease(text: str) : float
  - compute_passive_voice_ratio(text: str) : float
  - compute_sentiment_lm(text: str) : float
  - compute_uncertainty_ratio(text: str) : float
}

note right of LinguisticFeatureExtractor
  <b>Статический утилитный класс</b>
  Вычисляет лингвистические метрики:
  • Длина текста (Word Count)
  • Индекс туманности (Fog Index)
  • Удобочитаемость (Flesch Reading Ease)
  • Доля пассивных конструкций
  • Тональность (Loughran-McDonald)
  • Доля слов неопределённости
  
  <b>Не имеет состояния.</b>
  Все методы — чистые функции.
end note

class TextCleaner <<Utility>> {
  + clean(raw_text: str) : str
  ..
  - remove_html_tags(text: str) : str
  - remove_headers(text: str) : str
  - remove_legal_disclaimers(text: str) : str
  - normalize_whitespace(text: str) : str
}

note right of TextCleaner
  <b>Статический утилитный класс</b>
  Выполняет очистку текста:
  • Удаление HTML-тегов и заголовков
  • Удаление юридических оговорок
  • Нормализация пробелов
  
  <b>Важно:</b> НЕ удаляет цифры и
  НЕ удаляет все стоп-слова —
  как обосновано в разделе 1.1.5.
end note
