note right of AETrain
  <b>Получает список всех документов</b>
  (Fraud + Non-Fraud).
  
  В отличие от RFTrainer, который
  обучается на всех данных,
  AETrainer должен отфильтровать
  только Non-Fraud для обучения
  автоэнкодера.
end note

AETrain -> AETrain : filter_non_fraud()\nоставляет только label=0\nиз всего списка

note right of AETrain
  <b>Фильтрация Non-Fraud</b>
  Извлекает только документы с label=0
  из полученного списка.
  
  Автокодировщик обучается только
  на нормальных данных —
  это принципиально для
  unsupervised anomaly detection.
  
  Fraud-документы (label=1)
  отбрасываются на этом этапе.
end note

AETrain -> AETrain : split train/validation\n(80/20) на Non-Fraud

AETrain -> AETrain : построение архитектуры\nAutoencoderModel

note right of AETrain
  <b>Архитектура автоэнкодера:</b>
  Input(input_dim) → Dense(128, ReLU)
  → Dense(64, ReLU) → Dense(16, ReLU)
  → Dense(64, ReLU) → Dense(128, ReLU)
  → Dense(input_dim, Sigmoid)
  
  <b>Обучение:</b>
  • loss = MSE, optimizer = Adam(lr=0.001)
  • batch_size = 32, epochs ≤ 100
  • early stopping (patience = 10 эпох)
  
  Обучение только на Non-Fraud данных.
end note

AETrain -> AETrain : обучение на train\nс валидацией на validation

AETrain -> AETrain : compute_threshold()\n95-й перцентиль MSE\nна validation Non-Fraud

note right of AETrain
  <b>Вычисление порога:</b>
  MSE восстановления для валидации
  (только Non-Fraud).
  
  Порог = 95-й перцентиль распределения.
  95% нормальных — ниже порога,
  5% — выше (допустимые false positives).
  
  Этот порог будет использоваться
  при инференсе для классификации
  аномалий.
end note
