note bottom of Core
  <b>Все интерфейсы оперируют списками:</b>
  • prepare(rawData) → List<ProcessorInput>
  • process(List<ProcessorInput>) → List<ProcessorOutput>
  • train(List<ProcessorInput>) → void
  • interpret(List<ProcessorOutput>) → Any
  
  Пайплайны передают списки целиком
  между этапами.
end note

note bottom of User
  <b>Пользователь реализует интерфейсы,</b>
  работающие со списками.
  
  Для одного элемента — список из 1.
  
  Подготовка возвращает список DTO.
  Процессор обрабатывает весь список.
  Интерпретатор получает все результаты
  для агрегированной визуализации.
end note
