Inf -> Inf : получен List<FraudDetectionOutput>\nдля всех документов

Inf -> RFInterp : interpret(List<FraudDetectionOutput>)
activate RFInterp

note right of RFInterp
  <b>Агрегированная SHAP-интерпретация</b>
  
  Получает ВСЕ результаты сразу,
  каждый FraudDetectionOutput уже содержит
  готовые shap_values (вычислены в RFProcessor).
  
  Для каждого результата:
  1. Извлекает shap_values из FraudDetectionOutput
  2. Форматирует читаемый отчёт (format_report)
  
  <b>Агрегированная аналитика:</b>
  • Сводная статистика по всем документам
  • Распределение fraud_probability
  • Общие top-K признаки по всему набору
  • Сравнительный анализ результатов
  • Визуализация: summary plot, bar plot
    на основе агрегированных shap_values
  
  Интерпретатор НЕ вычисляет SHAP —
  он только агрегирует и визуализирует
  уже готовые значения.
end note

RFInterp --> Inf : сводный отчёт + агрегированная аналитика
deactivate RFInterp

Inf --> Dev : Any (сводный результат с аналитикой)
deactivate Inf
