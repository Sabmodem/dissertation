@startuml
!theme plain
skinparam participantBackgroundColor LightYellow
skinparam participantBorderColor DarkSlateGray
skinparam sequenceArrowColor DarkSlateGray

actor "ML Developer" as Dev2
participant "InferencePipeline" as Inf
participant "Preparator" as Prep2
participant "Processor" as Proc
participant "Interpreter" as Interp
collections "Файловая\nсистема" as FS2

Dev2 -> Inf : run(rawData)
activate Inf

Inf -> Prep2 : prepare(rawData)
activate Prep2

note right of Prep2
  <b>Этап подготовки</b>
  • Загрузка входных данных
  • Предобработка (нормализация,
    токенизация, resize и т.д.)
  • Формирование списка ProcessorInput
  
  Возвращает List<ProcessorInput>
  (для одного элемента — список из 1)
end note

Prep2 --> Inf : List<ProcessorInput>
deactivate Prep2

Inf -> Proc : process(List<ProcessorInput>)
activate Proc

Proc -> FS2 : загружает модель из файла (один раз)
note right of FS2
  <b>Загрузка модели</b>
  Из того же файла, что
  сохранил Trainer на этапе
  обучения.
  
  Модель загружается ОДИН раз
  для всего списка входов.
end note

Proc -> Proc : инференс для всех элементов списка
note right of Proc
  <b>Инференс</b>
  • Получает список всех входов
  • Загружает модель один раз
  • Для каждого элемента:
    - прямой проход модели
    - получение предсказаний
    - формирование ProcessorOutput
  • Возвращает список ProcessorOutput
  
  Может обрабатывать батчами
  для эффективности GPU/CPU.
end note

Proc --> Inf : List<ProcessorOutput>
deactivate Proc

Inf -> Interp : interpret(List<ProcessorOutput>)
activate Interp

Interp -> Interp : агрегированная постобработка
note right of Interp
  <b>Интерпретация</b>
  • Получает ВСЕ результаты сразу
  • Постобработка результатов
  • Генерация агрегированных отчётов:
    - гистограммы распределения
    - confusion matrix
    - сводные метрики
  • Запись в БД
  • Отправка алертов
  • Возврат в бизнес-формате
  
  Преимущество: видит всю картину
  для построения сводной статистики.
end note

Interp --> Inf : Any
deactivate Interp

Inf --> Dev2 : Any
deactivate Inf

@enduml
