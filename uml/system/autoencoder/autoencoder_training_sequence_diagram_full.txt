actor "Исследователь" as Dev
participant "TrainPipeline" as Train
participant "TextFraudPreparator" as Prep
participant "AETrainer" as AETrain
collections "Файловая\nсистема" as FS

Dev -> Train : run(rawData)
activate Train

' ========= Этап подготовки =========
Train -> Prep : prepare(rawData)
activate Prep

note right of Prep
  <b>fit_mode = True</b>
  Те же шаги, что и для RF:
  очистка, лингвистические признаки,
  обучение TfidfVectorizer и Scaler,
  формирование combined_features.
  
  <b>Ключевое отличие:</b>
  Preparator НЕ фильтрует Non-Fraud —
  он возвращает все документы.
  Фильтрацию выполняет AETrainer.
  
  Так достигается переиспользование
  Preparator'а между RF и AE.
end note

Prep -> FS : сохраняет артефакты\n(TfidfVectorizer, StandardScaler)

Prep --> Train : List[FraudDetectionInput]\n(все документы, с метками)
deactivate Prep

' ========= Этап обучения =========
Train -> AETrain : train(FraudDetectionInput)
activate AETrain

AETrain -> AETrain : filter_non_fraud()\nоставляет только label=0

note right of AETrain
  <b>Фильтрация Non-Fraud</b>
  Автокодировщик обучается только
  на нормальных данных.
  
  Это принципиально для
  unsupervised anomaly detection:
  модель учится восстанавливать
  "норму" и плохо восстанавливает
  аномалии.
end note

AETrain -> AETrain : split train/validation\n(80/20, случайно)

AETrain -> AETrain : построение архитектуры\nAutoencoderModel

note right of AETrain
  <b>Архитектура автоэнкодера:</b>
  Input (input_dim)
  → Dense(128) → ReLU
  → Dense(64) → ReLU
  → Dense(16) → ReLU  [bottleneck]
  → Dense(64) → ReLU
  → Dense(128) → ReLU
  → Dense(input_dim) → Sigmoid
  
  Обучение:
  • loss = MSE
  • optimizer = Adam(lr=0.001)
  • batch_size = 32
  • epochs ≤ 100 (early stopping
    при отсутствии улучшений
    val_loss за 10 эпох)
end note

AETrain -> AETrain : обучение на train\nс валидацией на validation

AETrain -> AETrain : compute_threshold()\n95-й перцентиль MSE\nна validation Non-Fraud

note right of AETrain
  <b>Вычисление порога:</b>
  Для каждого документа валидации
  вычисляется MSE восстановления.
  
  Порог = 95-й перцентиль
  распределения MSE.
  
  Это означает: 95% нормальных
  документов будут иметь ошибку
  ниже порога, 5% — выше
  (допустимые ложные срабатывания).
end note

AETrain -> FS : сохраняет артефакты\n• autoencoder_model.h5\n• anomaly_threshold.json

note right of FS
  <b>Сохраняемые артефакты:</b>
  • autoencoder_model.h5 —
    веса модели (обученный автоэнкодер)
  • anomaly_threshold.json —
    порог аномальности (число)
  
  TfidfVectorizer и Scaler уже
  сохранены Preparator'ом.
  
  <b>Для инференса потребуются</b>
  все три файла + артефакты Preparator'а.
end note

deactivate AETrain

Train --> Dev : void
deactivate Train
