note top of AEMod
  <b>Autoencoder:</b> unsupervised.
  Trainer + Processor + Interpreter.
  
  Все работают со списками:
  • train(List<FraudDetectionInput>) → void
    (фильтрует Non-Fraud внутри)
  • process(List<FraudDetectionInput>) → List<FraudDetectionOutput>
    (модель загружается один раз)
  • interpret(List<FraudDetectionOutput>) → Any
    (агрегированная гистограмма ошибок)
  <b>Важно:</b> AETrainer и AEProcessor
  НЕ управляют StandardScaler.
  Нормализация — зона ответственности
  Preparator'а.
  Модель загружается один раз
  для всего списка входов.
end note
