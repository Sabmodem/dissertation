package "Пользовательские Реализации" as User {
  component "MyPreparator" as MyPrep
  component "MyProcessor" as MyProc
  component "MyInterpreter" as MyInterp
  component "MyTrainer" as MyTrain
  component "MyInput расширяет\nnProcessorInput" as MyPI
  component "MyOutput расширяет\nProcessorOutput" as MyPO
}

' ========= Пользовательские реализации =========
MyPrep .up.|> PrepI : реализует
MyProc .up.|> ProcI : реализует
MyInterp .up.|> InterpI : реализует
MyTrain .up.|> TrainI : реализует
MyPI --|> PI : расширяет
MyPO --|> PO : расширяет

note right of User
  <b>Пользователь реализует:</b>
  • 4 интерфейса этапов (все работают со списками)
  • 2 контракта данных (DTO)
  
  <b>Сигнатуры:</b>
  • prepare(rawData) → List<ProcessorInput>
  • process(List<ProcessorInput>) → List<ProcessorOutput>
  • train(List<ProcessorInput>) → void
  • interpret(List<ProcessorOutput>) → Any
  
  Фреймворк вызывает пользовательский код
  через эти точки расширения.
  Для одного элемента — список из 1 элемента.
end note
