note right of RFTrain
  <b>Обучение Random Forest</b>
  Получает список всех документов.
  
  1. Извлекает X = combined_features, y = labels
     из всего списка
  2. StratifiedKFold (5 фолдов)
  3. RandomizedSearchCV:
     • n_estimators: {100, 200, 500}
     • max_depth: {10, 20, None}
     • min_samples_split: {2, 5, 10}
     • class_weight: {balanced, None}
  4. Оптимизация по F1-score
  5. Финальное обучение на всех данных
     с лучшими гиперпараметрами
  
  <b>Важно:</b> получает весь список целиком
  для формирования полной матрицы X и
  вектора y. Обучение происходит на всех
  данных (Fraud + Non-Fraud).
end note

RFTrain -> FS : сохраняет артефакты\n• rf_model.joblib\n• feature_names.json

note right of FS
  <b>Сохраняемые артефакты:</b>
  • rf_model.joblib — обученная модель
  • feature_names.json — имена признаков
    для SHAP-интерпретации
  
  TfidfVectorizer и StandardScaler уже
  сохранены Preparator'ом (на этапе подготовки).
  
  <b>Для инференса потребуются:</b>
  • Preparator загружает: tfidf_vectorizer.pkl, feature_scaler.pkl
  • RFProcessor загружает: rf_model.joblib, feature_names.json
  
  Таким образом, RFProcessor НЕ работает
  с векторизатором и скалером, получая
  уже нормализованные combined_features
  из FraudDetectionInput.
end note
