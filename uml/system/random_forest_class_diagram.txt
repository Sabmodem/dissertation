  + train(input: ProcessorInput) : void

' ========= Классы RF модуля =========
class RFTrainer <<User>> {
  - model: RandomForestClassifier
  - tfidf_vectorizer: TfidfVectorizer
  - feature_scaler: StandardScaler
  - feature_names: List[str]
  - model_path: str
  __
  + train(input: FraudDetectionInput) : void
  - perform_grid_search(X: ndarray, y: ndarray) : RandomForestClassifier
  - save_artifacts() : void
}

note top of RFTrainer
  <b>Реализация интерфейса Trainer</b>
  для Random Forest.
  
  <b>Вход:</b> FraudDetectionInput с
  заполненными combined_features и labels.
  
  <b>Логика обучения:</b>
  1. Извлекает combined_features (X)
     и labels (y).
  2. RandomizedSearchCV по сетке:
     n_estimators: {100, 200, 500}
     max_depth: {10, 20, None}
     min_samples_split: {2, 5, 10}
     class_weight: {balanced, None}
  3. Кросс-валидация: StratifiedKFold
     (5 фолдов) — сохраняет пропорцию
     классов при дисбалансе.
  4. Метрика оптимизации: F1-score
     (важнее баланс Precision/Recall
     при дисбалансе, а не Accuracy).
  
  <b>Сохраняет на диск:</b>
  • rf_model.joblib (модель)
  • tfidf_vectorizer.pkl
  • feature_scaler.pkl
  • feature_names.json
end note

class RFProcessor <<User>> {
  - model: RandomForestClassifier
  - tfidf_vectorizer: TfidfVectorizer
  - feature_scaler: StandardScaler
  - feature_names: List[str]
  - model_path: str
  __
  + process(input: FraudDetectionInput) : FraudDetectionOutput
  - load_artifacts() : void
}

note top of RFProcessor
  <b>Реализация интерфейса Processor</b>
  для Random Forest.
  
  <b>Загружает из model_path:</b>
  • rf_model.joblib
  • tfidf_vectorizer.pkl
  • feature_scaler.pkl
  • feature_names.json
  
  <b>Инференс:</b>
  1. Извлекает combined_features.
  2. model.predict_proba() →
     вероятность fraud.
  3. model.predict() → метка класса.
  4. Формирует FraudDetectionOutput.
  
  <b>Важно:</b> не выполняет
  предобработку текста — она уже
  выполнена Preparator'ом.
end note

class RFInterpreter <<User>> {
  - shap_explainer: shap.TreeExplainer
  __
  + interpret(output: FraudDetectionOutput) : Any
  - compute_shap_values(input: FraudDetectionInput, output: FraudDetectionOutput) : dict
  - format_report(report_id: str, probability: float, shap_values: dict) : str
}

note top of RFInterpreter
  <b>Реализация интерфейса Interpreter</b>
  для Random Forest.
  
  <b>Постобработка:</b>
  1. Вычисляет SHAP-значения для
     объяснения предсказания (XAI).
  2. Извлекает топ-K наиболее
     влиятельных признаков.
  3. Формирует объяснение:
     какие признаки и в какую сторону
     повлияли на решение модели.
  
  <b>Это реализует требование XAI</b>
  из глав 1 и 2.
  
  <b>В Production:</b> SHAP-объяснения
  могут быть сохранены в БД для аудита.
end note
