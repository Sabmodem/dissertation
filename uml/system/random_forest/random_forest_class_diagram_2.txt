note bottom of RFProcessor
  <b>Реализация интерфейса Processor</b>
  
  <b>Загружает из model_path (один раз для всего списка):</b>
  • rf_model.joblib
  • tfidf_vectorizer.pkl
  • feature_scaler.pkl
  • feature_names.json
  
  <b>Инференс для каждого элемента списка:</b>
  1. Извлекает combined_features
  2. model.predict_proba() → вероятность fraud
  3. model.predict() → метка класса
  4. Формирует FraudDetectionOutput
  
  <b>Возвращает:</b> List<FraudDetectionOutput>
  
  <b>Важно:</b> не выполняет предобработку
  текста — она уже выполнена Preparator'ом.
  Модель загружается один раз для всего
  списка входов.
end note
